# DBMS Assignment 3 – Local Case Study

## Local Case Study: Kirana / General Store

This assignment is a local case study of **Shanti Kirana Store**. The purpose of this assignment is to understand how a local business currently manages its data and how a **Database Management System (DBMS)** can improve data storage, searching, security, and management.

## Business Details

* **Business Type:** Kirana / General Store
* **Business Name:** Shanti Kirana Store
* **Person Interviewed:** RaghuDada (Shopkeeper)

## 1. Current Method

Shanti Kirana Store mainly maintains its records using:

* Notebooks and registers
* Paper bills
* Handwritten records
* Phone calls
* WhatsApp messages

The store maintains information about sales, stock, customer orders, suppliers, and customer dues.

## 2. Problems Identified

The current manual system has several limitations:

* Duplicate entries and data redundancy
* Inconsistent information
* Risk of losing or damaging records
* No complete digital backup
* Slow searching of old records
* Difficulty in tracking stock
* Difficulty in managing customer dues
* Limited security and access control
* Possibility of incorrect or conflicting entries

## 3. Proposed DBMS Solution

A relational DBMS can organize the store's information into structured tables such as:

* Products
* Sales
* Customers
* Suppliers
* Orders
* Customer Dues

The DBMS can help the store store, search, update, and manage its information more efficiently.

## 4. DBMS Components Studied

The assignment maps the following DBMS components to the activities of Shanti Kirana Store:

| DBMS Component                   | Purpose                                                     |
| -------------------------------- | ----------------------------------------------------------- |
| Query Processor                  | Searches for sales, stock, customer dues, and other records |
| Storage Manager                  | Stores and retrieves business records                       |
| Buffer Manager                   | Temporarily manages data while it is being accessed         |
| Transaction Manager              | Handles sales and related stock updates consistently        |
| DDL/DML Interpreter              | Creates database structures and performs data operations    |
| Authorization/Security Subsystem | Controls access to database information                     |

## 7. Deliverables

The final submission contains:

## Conclusion

This case study shows how a manual record-keeping system in a small Kirana store can be improved using a relational DBMS. A DBMS can provide better organization, faster searching, improved consistency, controlled access, and more reliable management of business records.
